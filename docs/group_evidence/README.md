## Part B reflection

The approved map distributes six plausible failures across data/context, prompt handling, the model, safety checks, feedback, and the user interface; no single component has the most annotations. Engineering effort should therefore cover the whole flow, with particular attention to output safety and evaluation because a misleading or unsafe answer can reach the user, and to feedback monitoring so recurring problems are not left unchecked.
